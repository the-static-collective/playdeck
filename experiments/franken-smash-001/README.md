# FRANKEN SMASH 001

A deliberately isolated deterministic-editor experiment that composes live ideas from:

- **Haunted Toaster** — Listening Eye six-lens selection pressure + batch-scale continuity.
- **Haunted Blender** — accepted moving takes, time-slicing, observer-local camera, memory residue, and capability addressing.
- **Playdeck** — six-up possibility ecologies, causal distinction, KEEP/SCRAPE, and continuation authority.
- **Dogram** — delta measurement without grading or creative authority.

It does **not** merge those repositories or claim their experimental branches are canonical. The browser experiment pins the exact branch heads inspected when this specimen was built and treats them as source witnesses.

## What it proves

`index.html` is a dependency-free composition cockpit with:

1. deterministic seed + parameter replay;
2. six complementary art-direction candidates;
3. an editable eight-section composition plan;
4. a frame-addressable 16:9 preview in a deliberately simple anime/graphic language;
5. bounded Blender-style door, observer, time-slice, and memory-residue behavior;
6. Playdeck-style `PROPOSAL -> KEEP -> PREVIEW WITNESS` authority stages;
7. SCRAPE opening a new deterministic family without treating rejected candidates as negative training data;
8. Dogram-style transform metrics explicitly marked `measurement-only`;
9. exportable JSON receipt with source pins, plan digest, measurements, overrides, and authority class.

## Why an isolated experiment

The branch ecologies we are borrowing from are intentionally not one merged runtime. This specimen therefore composes **interfaces and laws**, not Git histories.

```text
TOASTER lenses / album pressure
        |
        v
PLAYDECK six-up ecology ---- human KEEP
        |                         |
        |                         v
        +----> CompositionPlan -> deterministic preview
                                  |
BLENDER cinematic organs --------+
                                  |
DOGRAM measures delta ------------+
                                  |
                                  v
                               WITNESS
```

## Current visual language

The default `weird-simple-anime` renderer is intentionally cheap and synthetic: line-art figure, contact-sheet cards, hinged door, afterimage memory, time-slice strips, bounded portal, particles, room perspective. It is a proof that the composition grammar can become visually legible without depending on a generative video model.

A later adapter could replace only the renderer while keeping the plan and receipt stable.

## Laws retained

```text
SOURCE != PLAN
PLAN != RENDER
PROPOSAL != HISTORY
MEMORY != PRESENT FACT
MEASUREMENT != GRADE
KEEP = CONTINUATION PERMISSION
WITNESS = RESOLVED PREVIEW EXECUTION
```

## Preview witness boundary

`WITNESS PREVIEW` seals the deterministic browser execution only. It is **not** a canonical Toaster/Blender render receipt, publication event, or claim that a production MP4 occurred.
